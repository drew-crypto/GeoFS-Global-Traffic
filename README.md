# GeoFS-Global-Traffic
Adds planes all around the globe in GeoFS


Here are the steps in order to correctly implement the Global Traffic add-on into GeoFS:

So in the begginning you want to copy and paste the code in "main.js" into the GeoFS console or Tampermonkey extension. Then:


1st: Access the "options" panel in-game.
![Option panel 1](https://github.com/drew-crypto/GeoFS-Global-Traffic/blob/48f6759b17a1840a990c17057ccc837d38033e8f/Images/Capture%20d'%C3%A9cran%202026-08-09%20203733.png)

![Option panel 2](https://github.com/drew-crypto/GeoFS-Global-Traffic/blob/48f6759b17a1840a990c17057ccc837d38033e8f/Images/Capture%20d'%C3%A9cran%202026-08-09%20203746.png)

2nd: Click on the "Global Traffic" button.

![Global Trafic button](https://github.com/drew-crypto/GeoFS-Global-Traffic/blob/48f6759b17a1840a990c17057ccc837d38033e8f/Images/Capture%20d'%C3%A9cran%202026-08-09%20203806.png)

3rd adjust the settings according to your will:

![Settings 1](https://github.com/drew-crypto/GeoFS-Global-Traffic/blob/48f6759b17a1840a990c17057ccc837d38033e8f/Images/Capture%20d'%C3%A9cran%202026-08-09%20203817.png)

You can turn it ON/OFF by pressing the "Set Global Traffic":

![Settings 2](https://github.com/drew-crypto/GeoFS-Global-Traffic/blob/48f6759b17a1840a990c17057ccc837d38033e8f/Images/Capture%20d'%C3%A9cran%202026-08-09%20203829.png)

![Settings 3](https://github.com/drew-crypto/GeoFS-Global-Traffic/blob/48f6759b17a1840a990c17057ccc837d38033e8f/Images/Capture%20d'%C3%A9cran%202026-08-09%20203845.png)

Change the density of aircrafts in the render zone attributed and join the discord server:

![Settings 4](https://github.com/drew-crypto/GeoFS-Global-Traffic/blob/main/Images/Capture%20d'%C3%A9cran%202026-08-09%20203901.png?raw=true)
